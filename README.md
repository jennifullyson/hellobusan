# helloBusan

**Your Busan trip, handled** — a friendly travel & concierge website for visitors to Busan, South Korea.

A single-page site built as one self-contained `index.html` (no build step, no dependencies), covering:

- **Home** — overview of the services
- **Services** — Private Tour Guide · Reservation (stays, dining, private car with live price estimate) · Shopping · Translation · Medical Tour · VIP Concierge
- **For Business** — Korean business connections & support
- **Contact** — enquiry form and contact details

## View it locally

Just open `index.html` in any web browser — that's it.

## Publish free with GitHub Pages

1. Create a new repository on GitHub and upload these files (or push this folder).
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose the `main` branch and the `/ (root)` folder, and **Save**.
4. After a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

Because the page is named `index.html`, GitHub Pages serves it automatically.

## Notes

- The booking and enquiry forms are front-end demos — they show a confirmation message but don't send anything yet. Connect them to an email/form service (e.g. Formspree, Getform) to receive real submissions.
- Contact details (email, phone, KakaoTalk, address) are placeholders — replace them with your real info.
- Fonts load from Google Fonts, so the page looks best online; offline it falls back to system fonts.
